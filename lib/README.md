# PostgreSQL JDBC Driver

Download the PostgreSQL JDBC driver from:
https://jdbc.postgresql.org/download/

Choose the JDBC 4.2 driver for Java 8 or newer.

Place the downloaded postgresql-\*.jar file in this directory.

The JAR is excluded from Git by the project's .gitignore.
Each team member must download the driver before running the application.

Include lib/\* in the Java classpath when running JDBC code.
